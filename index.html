¿QUIÉNES SOMOS?

GRINGA.EXE es un sistema de servicio de alimentos inspirado en la estética arcade de los videojuegos clásicos.

El sistema permite seleccionar productos, personalizar las gringas, elegir bebidas, gestionar el pedido y realizar el proceso de pago desde una interfaz digital.
